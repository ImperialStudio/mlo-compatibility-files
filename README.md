<h1>Vangelico Extension + MarKz3D iFruit Store Rockford Compatibility</h1>
These files allow you to use our Vangelico Extension MLO along side MarKz3D's iFruit Rockford store MLO<br>
<br>
Seen here: <url>https://www.markz3d.com/products/maps/ifruit-store</url>
<br>
<h3>Instructions</h3>
If you have Markz3D ifruit store mlo in Rockford you will need to use these files.
Drag the stream folder into imperial-jewel-extension folder overwriting the 4 files when prompted.<br>
<br>
Remove these 3 files listed below from cfx-mxc-ifruitstore resource.
Located in the folder: cfx-mxc-ifruitstore\stream\[multi-location]\[1-RockfordHills]\[gta5files]<br>

- bh1_16_0.ybn
- hi @ bh1_16_0.ybn
- bh1_16_bld03_det.ydr

The follow is the occlusion ymap file which you will need to use both mlo's at the same time. Make sure you server doesn't have another version of this file anywhere.
- hei_bh1_occl_05.ymap<br>
<br>
Now both mlos will be able to run at the same time without conflicting files.<br>
