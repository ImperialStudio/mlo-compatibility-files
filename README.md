<h1>Vangelico Extension + MarKz3D iFruit Store Rockford Compatibility</h1>
These files will allow you to use our Vangelico Extension MLO along side MarKz3D's iFruit Rockford location MLO<br>
<br>
Seen here: <url>https://www.markz3d.com/products/maps/ifruit-store</url>
<br>
<h3>Instructions</h3>
If you have Markz3D ifruit store mlo in Rockford you will need to use these files.
Download the .zip file containing the files.
Then drag the stream folder into the imperial-jewel-extension folder overwriting the 4 files when prompted.<br>
<br>
Remove these 3 files listed below from the cfx-mxc-ifruitstore resource.
Located in the folder: cfx-mxc-ifruitstore\stream\[multi-location]\[1-RockfordHills]\[gta5files]<br>

- bh1_16_0.ybn
- hi@bh1_16_0.ybn
- bh1_16_bld03_det.ydr

The following (4th) file is the occlusion ymap file which you will need to be able to use both the mlo's at the same time. Also Make sure you server doesn't have another version of this file in any other resource. (Typically also found in city hall / DOJ building mlo's)
- hei_bh1_occl_05.ymap<br>
<br>
If you following the steps correctly both mlo's will be able to be run at the same time without any conflicting files.<br>
